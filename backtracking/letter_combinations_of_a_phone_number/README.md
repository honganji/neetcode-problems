# Letter Combinations of a Phone Number

[LeetCode](https://leetcode.com/problems/letter-combinations-of-a-phone-number/)

Given a string of digits from 2 to 9, list every letter string that could be typed on an old phone keypad, where each digit contributes one of its letters. An empty input gives an empty list.
