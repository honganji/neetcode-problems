# Longest Repeating Character Replacement

[LeetCode](https://leetcode.com/problems/longest-repeating-character-replacement/)

Given a string of uppercase letters and a number `k`, you may change at most
`k` characters; return the length of the longest substring you can turn into a
single repeated letter.
