# Best Time to Buy and Sell Stock

[LeetCode](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)

Given daily stock prices, pick one day to buy and a later day to sell so the
profit is as large as possible; return that profit, or 0 if no trade makes
money.
