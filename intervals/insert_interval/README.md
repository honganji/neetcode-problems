# Insert Interval

[LeetCode](https://leetcode.com/problems/insert-interval/)

You are given a list of non-overlapping intervals sorted by start, plus one new interval. Insert the new interval, merging it with any intervals it overlaps, and return the sorted, non-overlapping result.
