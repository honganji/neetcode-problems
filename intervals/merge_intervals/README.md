# Merge Intervals

[LeetCode](https://leetcode.com/problems/merge-intervals/)

Given a list of `[start, end]` intervals, merge every group that overlaps (touching counts as overlapping) and return the non-overlapping intervals that cover the same ranges, sorted by start.
