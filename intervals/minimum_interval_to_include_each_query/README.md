# Minimum Interval to Include Each Query

[LeetCode](https://leetcode.com/problems/minimum-interval-to-include-each-query/)

Given a list of intervals `[left, right]` (inclusive) and a list of query points, return for each query the length of the smallest interval that contains it, or `-1` if no interval does.
