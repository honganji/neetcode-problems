# Non-overlapping Intervals

[LeetCode](https://leetcode.com/problems/non-overlapping-intervals/)

Given a list of intervals, find the fewest intervals to remove so that the rest
don't overlap. Intervals that only touch at an endpoint (like `[1, 2]` and
`[2, 3]`) don't count as overlapping.
