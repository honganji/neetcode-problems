# Implement Trie (Prefix Tree)

[LeetCode](https://leetcode.com/problems/implement-trie-prefix-tree/)

Design a tree-shaped structure for lowercase words that supports inserting a
word, checking whether a whole word was inserted, and checking whether any
inserted word starts with a given prefix.
