# Regular Expression Matching

[LeetCode](https://leetcode.com/problems/regular-expression-matching/)

Given a string `s` and a pattern `p` made of lowercase letters, `.` (matches any single character), and `*` (matches zero or more of the character before it), decide whether the pattern matches the entire string.
