# Longest Increasing Path in a Matrix

[LeetCode](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/)

Given an m x n grid of integers, find the length of the longest path that moves up, down, left, or right and where each step goes to a strictly larger number.
