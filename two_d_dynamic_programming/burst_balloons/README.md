# Burst Balloons

[LeetCode](https://leetcode.com/problems/burst-balloons/)

Given a row of balloons with numbers, pop them one at a time to collect `left × current × right` coins (out-of-range neighbors count as 1), and return the most coins you can collect.

Only two genuinely different techniques exist for this problem, so each language has two solutions rather than three. A third option (top-down memoized recursion, or plain backtracking over burst orders) is just the same recurrence or the same search as one of these, not a new technique.
