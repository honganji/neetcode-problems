# Distinct Subsequences

[LeetCode](https://leetcode.com/problems/distinct-subsequences/)

Given two strings `s` and `t`, count the ways `t` can be formed by deleting some characters from `s` without reordering the rest. Two ways are different if they keep different positions of `s`.

## Languages

- [Dart](Dart/README.md)
- [Python](Python/README.md)
- [Swift](Swift/README.md)
- [Kotlin](Kotlin/README.md)

Only two genuinely different techniques exist for this problem, so each language has two solutions rather than three.
