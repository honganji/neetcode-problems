# Hand of Straights

[LeetCode](https://leetcode.com/problems/hand-of-straights/)

Given a hand of cards (integers) and a group size, can you split the whole hand into groups of exactly that size where each group holds consecutive values?

Only two techniques are meaningfully different for this problem, so only two solutions are given per language. A min-heap version exists, but it is the same greedy idea as solution 1 with a heap instead of sorting, so it is not listed separately.
