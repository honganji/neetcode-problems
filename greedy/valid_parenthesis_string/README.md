# Valid Parenthesis String

[LeetCode](https://leetcode.com/problems/valid-parenthesis-string/)

Given a string made of `(`, `)` and `*`, decide whether the `*` characters can each be read as `(`, `)`, or nothing, so that the parentheses come out balanced.
