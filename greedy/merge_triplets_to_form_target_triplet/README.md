# Merge Triplets to Form Target Triplet

[LeetCode](https://leetcode.com/problems/merge-triplets-to-form-target-triplet/)

Given a list of triplets `[a, b, c]` and a target `[x, y, z]`, you may repeatedly merge two triplets by replacing one with the element-wise max of both. Return whether some triplet can become exactly the target.
