# Gas Station

[LeetCode](https://leetcode.com/problems/gas-station/)

There is a circular route of n gas stations. Station i gives you `gas[i]` fuel, and it costs `cost[i]` fuel to drive to the next station. Return the index you can start at with an empty tank to drive once around the circle, or `-1` if no start works.
