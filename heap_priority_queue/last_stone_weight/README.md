# Last Stone Weight

[LeetCode](https://leetcode.com/problems/last-stone-weight/)

Given stone weights, repeatedly smash the two heaviest: if they are equal both are destroyed, otherwise the lighter one is subtracted from the heavier one and the remainder goes back in. Return the weight of the last stone, or 0 if none remain.
