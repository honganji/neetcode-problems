# Task Scheduler

[LeetCode](https://leetcode.com/problems/task-scheduler/)

Given a list of CPU tasks (each labeled with a letter A–Z) and a cooldown `n`, find the minimum number of time units needed to run all tasks, where identical tasks must be at least `n` units apart and the CPU may sit idle.
