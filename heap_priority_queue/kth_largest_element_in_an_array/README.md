# Kth Largest Element in an Array

[LeetCode](https://leetcode.com/problems/kth-largest-element-in-an-array/)

Given an integer array `nums` and an integer `k`, return the kth largest value in the array (counting duplicates separately, so the answer is the value at position `k` in descending order).
