# Time Based Key-Value Store

[LeetCode](https://leetcode.com/problems/time-based-key-value-store/)

Design a map where each key stores many values tagged with increasing
timestamps, and a lookup returns the value whose timestamp is the largest one
not exceeding the requested time.
