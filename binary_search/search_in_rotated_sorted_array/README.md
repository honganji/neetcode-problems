# Search in Rotated Sorted Array

[LeetCode](https://leetcode.com/problems/search-in-rotated-sorted-array/)

Given a sorted array of distinct integers that has been rotated at some
unknown pivot, return the index of a target value (or -1 if it is absent) in
O(log n) time.
