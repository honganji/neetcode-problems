# Min Cost Climbing Stairs

[LeetCode](https://leetcode.com/problems/min-cost-climbing-stairs/)

Each step of a staircase has a cost. You may start on step 0 or step 1, and each move climbs one or two steps while paying the cost of the step you land on; return the least total cost to reach the top (just past the last step).
