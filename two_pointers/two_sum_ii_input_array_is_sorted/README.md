# Two Sum II - Input Array Is Sorted

[LeetCode](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/)

Given an array already sorted in non-decreasing order and a target, return the
1-indexed positions of the two numbers that add up to the target, using only
constant extra space.

The hash map from the original Two Sum still works here, but it ignores the
one thing this version gives you for free — the sorted order — and its O(n)
map breaks the O(1) extra space requirement, so it is left out.
