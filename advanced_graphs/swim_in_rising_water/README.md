# Swim in Rising Water

[LeetCode](https://leetcode.com/problems/swim-in-rising-water/)

Given an n×n grid where every cell has a distinct height from 0 to n²−1, find the smallest time at which you can walk from the top-left to the bottom-right corner (up, down, left, or right) using only cells whose height is at most that time.
