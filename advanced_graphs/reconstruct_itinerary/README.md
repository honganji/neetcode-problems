# Reconstruct Itinerary

[LeetCode](https://leetcode.com/problems/reconstruct-itinerary/)

Given a list of flight tickets `[from, to]`, rebuild the trip that starts at `"JFK"` and uses every ticket exactly once, returning the lexicographically smallest valid route.
