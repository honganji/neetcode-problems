# Evaluate Reverse Polish Notation

[LeetCode](https://leetcode.com/problems/evaluate-reverse-polish-notation/)

Given a list of tokens in Reverse Polish Notation (numbers and the operators
`+`, `-`, `*`, `/`, with each operator written after its two operands), compute
the value of the expression, truncating division toward zero.
