# Binary Tree Maximum Path Sum

[LeetCode](https://leetcode.com/problems/binary-tree-maximum-path-sum/)

Given a binary tree whose values may be negative, return the largest sum of any
path — a chain of connected nodes with at least one node that never revisits a
node and need not pass through the root.
