# Set Matrix Zeroes

[LeetCode](https://leetcode.com/problems/set-matrix-zeroes/)

Given an `m x n` matrix, if an element is `0`, set its entire row and column to `0`. Do it in place.

Only two of the three techniques here are genuinely different efficient ideas: the flag arrays (2) and the in-place markers (1). The brute force (3) is the naive version of the flag idea, kept as a baseline to show why the first two track the zeros instead of rescanning for them.
