## The big idea

数字がいっぱい書かれたカードの山を想像してみて。同じ数字のカードが2枚紛れてないか知りたい。でも1枚ずつ全部のカードと見比べていったら、ものすごく時間がかかっちゃうよね。

そこでこうする。まずカードを全部、小さい順番に並べる。背の順に並ぶ子どもたちみたいにね。そうすると、もし同じ数字のカードが2枚あったら、それは絶対に「お隣さん」同士になるんだ。だから、もう全部のカードを見比べなくていい。隣同士だけチェックすればOK!

## How the code does that

```python
def contains_duplicate(nums: list[int]) -> bool:
    sorted_nums = sorted(nums)
    for i in range(1, len(sorted_nums)):
        if sorted_nums[i] == sorted_nums[i - 1]:
            return True
    return False
```

1. `sorted_nums = sorted(nums)` — まずカード(数字)を全部、小さい順にきれいに並べる。これが「背の順に並ばせる」ところ。
2. `for i in range(1, len(sorted_nums)):` — 並んだ列を、2番目のカードから順番に歩いていく。
3. `if sorted_nums[i] == sorted_nums[i - 1]:` — 今立ってるカードと、すぐ前のお隣さんを見比べる。
4. `return True` — もし数字が同じだったら、「見つけた!ダブりがあったよ!」って言って、そこで終わり。
5. `return False` — 列の最後まで歩いても誰もお隣さんと同じじゃなかったら、「ダブりは無かったよ」って報告する。

## Why it's clever

並べ替えずに「全部のカード同士を総当たりで比べる」と、カードが多いときはとんでもない回数の見比べが必要になっちゃう。でも先に並び替えておけば、同じ数字は必ずピッタリ隣に来るから、1回ずつお隣さんと見比べるだけで済む。「並べる」というひと手間をかけることで、後の確認作業がすごく楽になるのが、このコードの賢いところだよ。
