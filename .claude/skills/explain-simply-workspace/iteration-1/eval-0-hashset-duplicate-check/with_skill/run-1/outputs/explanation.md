## 大事なイメージ

シールを集めるのが好きな君を想像してみて。たくさんシールが入った袋があって、1枚ずつ取り出して、自分の「シール帳」に貼っていくとする。

シールを貼る前に、いつも一瞬だけ確認するよね。「あれ、このシール、もう帳面に貼ってあったっけ？」って。もし帳面にまったく同じシールがもうあったら、「あ、かぶっちゃった！」って気づく。これが「かぶっているシールを見つける」ゲームだよ。

## コードがどうやってそれをやっているか

```swift
func containsDuplicate(_ nums: [Int]) -> Bool {
    var seen = Set<Int>()
    for num in nums {
        if !seen.insert(num).inserted {
            return true
        }
    }
    return false
}
```

1. `var seen = Set<Int>()`
   → これが「シール帳」。最初は空っぽ。まだ何も貼ってない。

2. `for num in nums {`
   → これは「袋の中からシールを1枚ずつ順番に取り出す」ところ。`num` が、今手に持っているシール1枚だよ。

3. `if !seen.insert(num).inserted {`
   → ここが一番大事なところ！ 今持っているシールを「シール帳に貼ってみる」んだ。
   - もし帳面にまだ貼ってなかったら → すんなり貼れる。何も起きないで次のシールに進む。
   - もし帳面に「もう貼ってあった」ら → 貼れない！「あ、これかぶりだ！」ってわかる。

4. `return true`
   → かぶりを見つけたら、「かぶってるシールがあったよ！」って答えを出して、ゲーム終了。

5. `return false`
   → 袋のシールを全部チェックして、1回もかぶらなかったら、「かぶりは無かったよ」って答えを出す。

## なぜこのやり方が賢いのか

ふつうに考えると、「帳面を見て、もうあるか確認する」のと「帳面に貼る」のは別々の作業に思えるよね。

でもこのコードの賢いところは、`seen.insert(num)` の一回の動きで、

- 「もう貼ってあるか確認する」
- 「貼ってなければ貼る」

を**同時に**やってくれるところなんだ。しかも `.inserted` を見れば、「ちゃんと新しく貼れたか、それとも既にあって貼れなかったか」が一瞬でわかる。

これは、シール帳を「見る→もう一度見て判断する→貼る」って3回手を動かす代わりに、「貼ろうとする、その一回の動きだけで全部わかっちゃう」っていう、手間を1回分省いている賢い技なんだよ。

ちなみに、このシール帳みたいな「見たものをすぐ覚えられる仕組み」のことを、プログラマーの人たちは「ハッシュセット（hash set）」って呼ぶよ。難しい名前だけど、やってることは君のシール帳と同じ、「もう見たことあるかどうかを、すぐ思い出せるようにしておく道具」ってだけなんだ。
