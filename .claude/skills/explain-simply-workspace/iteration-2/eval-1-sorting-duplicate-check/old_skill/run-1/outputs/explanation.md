## The big idea

数字が書かれたカードの山があると想像してください。その中に同じ数字のカードが2枚紛れていないか調べたいとします。全部のカードを、他の全部のカードと一枚ずつ見比べるのはとても大変です。でも、カードを小さい順に一列に並べてしまえば話は簡単になります。もし同じ数字のカードが2枚あったら、並べ替えたあとは必ず隣同士に並ぶからです。だから、列を端から端まで歩いていって「今見ているカードと左隣のカードが同じ数字かどうか」だけをチェックすればよくなります。

## How the code does that

1. `sorted_nums = sorted(nums)`
   これが「カードを小さい順に並べ直す」部分です。バラバラだった数字のリストを、小さい順にきれいな一列にします。

2. `for i in range(1, len(sorted_nums)):`
   並んだ列を、2番目のカードから順番に歩いていきます。1番最初のカードには「左隣」がいないので、2番目から見始めます。

3. `if sorted_nums[i] == sorted_nums[i - 1]:`
   「今見ているカード」と「その左隣のカード」が同じ数字かどうかをチェックします。並べ替えたあとなので、もし同じ数字のペアが元のリストのどこかにあったなら、ここで必ず隣り合っているはずです。

4. `return True`
   隣同士で同じ数字を見つけた瞬間、「重複あり!」とすぐに答えて処理を終わります。わざわざ残りのカードまで見る必要はありません。

5. `return False`（ループの外)
   列を最後まで歩いても同じ数字のペアが一度も見つからなければ、「重複なし」と答えます。

## Why it's clever

全部のカードを他の全部のカードと総当たりで見比べる方法だと、カードの枚数が増えるほど比べる回数が爆発的に増えてしまいます(専門用語で言うと計算量 O(n²))。でも先に並べ替えておけば、同じ数字は絶対に隣同士にしかならないので、列を1回歩くだけ(先頭から最後まで1回ずつ、専門用語では O(n))で済みます。並べ替え自体にも少し手間(O(n log n))がかかりますが、それでも総当たりよりずっと速く、しかも新しい箱(メモリ)をほとんど使わずに済むという利点もあります。
