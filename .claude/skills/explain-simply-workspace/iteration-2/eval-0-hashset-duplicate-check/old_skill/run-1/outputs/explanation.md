## おおきな考え方

シールあつめを想像してみて。シールをふくろから1まいずつ出して、じぶんの「シールアルバム」にはっていくとする。新しいシールを出すたびに、まず考えるよね。「あれ、このシール、もうアルバムに貼ってあったかな?」って。もしもう貼ってあったら「あ、これ2まい持ってる!」とわかる。まだ貼ってなかったら、アルバムにペタッとはって、次のシールにいく。ぜんぶのシールを見終わっても「もう貼ってある」がいちども起きなければ、同じシールは1まいもなかった、ということ。

## コードはどうやってそれをやっているか

```swift
func containsDuplicate(_ nums: [Int]) -> Bool {
    var seen = Set<Int>()
    for num in nums {
        if !seen.insert(num).inserted {
            return true
        }
    }
    return false
}
```

1. `var seen = Set<Int>()` ← これが「からっぽのシールアルバム」を用意するところ。まだ何も貼ってない。
2. `for num in nums` ← ふくろから数字(シール)を1こずつ取り出していくところ。
3. `seen.insert(num)` ← そのシールをアルバムに貼ろうとする動き。
4. `.inserted` は「新しく貼れたかどうか」を教えてくれる。初めて見るシールなら `true`(新しく貼れた)、もう貼ってあったシールなら `false`(貼れなかった、もうあった)。
5. `if !seen.insert(num).inserted` は「もし新しく貼れなかったら」という意味。つまり「もうアルバムにあった!」というとき。そのときは `return true` で「同じのがあったよ!」と答える。
6. 最後まで一度も「もうあった」が起きなければ、ループが終わって `return false`。「同じシールはなかったよ」という答え。

## なぜこれがかしこいか

ふつうに考えると、「アルバムを見て、あるか確認する」のと「アルバムに貼る」のは別々の作業だよね。でもこのコードの `seen.insert(num)` は、1回の動きで「貼る」と「もうあったかどうか教えてくれる」を同時にやってくれる。まほうのシール台紙に押しつけると、「あ、ここもう埋まってたよ」か「はい、新しく貼れたよ」かを、その場ですぐ教えてくれるイメージ。見る→貼るを2回にわけなくていいから、手間が半分になる。これが「clever bit(かしこいところ)」。グローンアップのプログラマーは、このシールアルバムのことを「ハッシュセット(hash set)」と呼ぶんだけど、やってることは「もう見たものをすごく速く覚えておく箱」というだけだよ。
