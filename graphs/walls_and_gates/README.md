# Walls and Gates

[LeetCode](https://leetcode.com/problems/walls-and-gates/)

Given a grid where -1 is a wall, 0 is a gate, and INF is an empty room, fill each empty room with the distance to its nearest gate, or leave it as INF if no gate can reach it.
