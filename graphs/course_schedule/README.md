# Course Schedule

[LeetCode](https://leetcode.com/problems/course-schedule/)

Given `numCourses` courses and a list of prerequisite pairs `[a, b]` (you must take `b` before `a`), return `true` if you can finish every course, which means the prerequisite graph contains no cycle.
