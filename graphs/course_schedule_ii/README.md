# Course Schedule II

[LeetCode](https://leetcode.com/problems/course-schedule-ii/)

Given `numCourses` courses and prerequisite pairs `[a, b]` (you must take `b` before `a`), return an order that lets you finish every course, or an empty list if that's impossible.
