# Redundant Connection

[LeetCode](https://leetcode.com/problems/redundant-connection/)

Given a tree of n nodes (labeled 1 to n) with one extra edge added, return the edge to remove so the graph becomes a tree again. If several edges qualify, return the one that appears last in the input.
