# Rotting Oranges

[LeetCode](https://leetcode.com/problems/rotting-oranges/)

Given a grid of empty cells, fresh oranges, and rotten oranges, find how many minutes it takes for every fresh orange to rot (rot spreads to up/down/left/right neighbors each minute), or return -1 if some fresh orange can never rot.
