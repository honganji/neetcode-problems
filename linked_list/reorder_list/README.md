# Reorder List

[LeetCode](https://leetcode.com/problems/reorder-list/)

Given a singly linked list L0 → L1 → … → Ln, rearrange it in place so the
nodes alternate from the two ends: L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → ….
