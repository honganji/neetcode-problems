# Copy List with Random Pointer

[LeetCode](https://leetcode.com/problems/copy-list-with-random-pointer/)

Given a linked list where each node also has a `random` pointer to any node
(or null), build a deep copy whose `next` and `random` pointers mirror the
original but point only at new nodes.
