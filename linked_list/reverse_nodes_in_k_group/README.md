# Reverse Nodes in k-Group

[LeetCode](https://leetcode.com/problems/reverse-nodes-in-k-group/)

Given a linked list, reverse every run of `k` consecutive nodes; if fewer than
`k` nodes are left at the end, leave them in their original order.
