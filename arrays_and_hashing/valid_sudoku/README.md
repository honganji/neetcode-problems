# Valid Sudoku

[LeetCode](https://leetcode.com/problems/valid-sudoku/)

Given a partially filled 9x9 Sudoku board, determine whether the digits already
placed break any rule: no digit may repeat within a row, a column, or one of
the nine 3x3 boxes.
