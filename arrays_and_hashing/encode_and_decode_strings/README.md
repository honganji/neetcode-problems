# Encode and Decode Strings

[LeetCode](https://leetcode.com/problems/encode-and-decode-strings/)

Design an `encode` that turns a list of strings into a single string, and a
`decode` that turns it back into the exact same list, even when the strings
contain any character (including whatever you use as a separator).
