# NeetCode Problems

Solutions and notes as I work through the [NeetCode](https://neetcode.io/) problem set.

## Structure

Each problem gets its own folder, containing the solution and a short write-up of my approach, key insights, and complexity analysis.

## Roadmap

Following the [NeetCode Roadmap](https://neetcode.io/roadmap), which lays out problems in a recommended learning order across the categories below. Each category builds on patterns from the previous ones, so working through it top to bottom is the intended path:

1. Arrays & Hashing
2. Two Pointers
3. Sliding Window
4. Stack
5. Binary Search
6. Linked List
7. Trees
8. Tries
9. Heap / Priority Queue
10. Backtracking
11. Graphs
12. Advanced Graphs
13. 1-D DP
14. 2-D DP
15. Greedy
16. Intervals
17. Math & Geometry
18. Bit Manipulation

## Progress

Tracking problems as I go, following the roadmap order above.
