# NeetCode Problems

Solutions and notes as I work through the [NeetCode](https://neetcode.io/) problem set.

## Structure

Each problem gets its own folder, containing the solution and a short write-up of my approach, key insights, and complexity analysis.

## Progress

Tracking problems as I go, organized by NeetCode's roadmap categories (Arrays & Hashing, Two Pointers, Sliding Window, Stack, Binary Search, Linked List, Trees, Tries, Heap/Priority Queue, Backtracking, Graphs, Advanced Graphs, 1-D DP, 2-D DP, Greedy, Intervals, Math & Geometry, Bit Manipulation).
